# Provenance: what is measured, derived, calibrated or synthetic

Every number this package produces is one of four kinds. They are separated here
because mixing them is how a sandbox starts looking like a prediction tool.

| kind | meaning | trust |
|---|---|---|
| **derived** | follows from a formula stated in the code and cited below | high — checkable algebra |
| **cited** | an empirical coefficient taken from literature, used at its stated order of magnitude | medium — right order, not site-specific |
| **assumed** | a number chosen to make the model behave plausibly; no source | low — comparative use only |
| **synthetic** | generated by `site.synthesize()` to provide a runnable example | zero as evidence about a real place |

## Per-quantity classification

| quantity | where | kind | note |
|---|---|---|---|
| Bearing factors `Nq, Nc, Nγ` | `verifiers.bearing_factors` | derived | Vesic closed form; tested against `18.40 / 30.14 / 22.40` at φ=30° |
| Shape and depth factors | `verifiers.shape_factors` | derived | Terzaghi shape, linear depth factors (an approximation, stated) |
| Ultimate bearing capacity | `verifiers.bearing_capacity` | derived | superposition of three terms; no drainage time, no liquefaction |
| Elastic settlement | `verifiers.elastic_settlement` | derived | `s = q·B·(1−ν²)·I/E`, `I` fixed at 0.82/0.95 |
| Infinite-slope factor of safety | `verifiers.verify_slope` | derived | with hydrostatic pore pressure from the water table |
| Landsat-style contact pressure | `verifiers.verify_landing` | derived | `p = m·g/(n·A)`, dynamic factor `1 + a/g` |
| Water-table depth | `hydrology.step` | derived + assumed | TWI `ln(a/tanβ)` mapped to `0.4–12 m`; the two constants are assumed |
| PET | `hydrology.annual_pet` | derived | Hargreaves, FAO-56 radiation |
| Actual evapotranspiration | `hydrology._budyko` | derived | Budyko curve, standard form |
| Infiltration split | `hydrology.step` | assumed | `0.45 + 0.6·log10(k/1e-5)`, slope reduction |
| `GPP_REF = 1.65`, `RESP_FRAC = 0.48` | `vegetation.py` | assumed | chosen so that NPP lands in the 0.3–1.0 kg C m⁻² yr⁻¹ range |
| PFT parameters (Vcmax, SLA, g1, envelopes) | `pft.py` | cited ranges, **not calibrated** | plausible for the biome class, not fitted to any site |
| `FORAGE_GRASS 0.22`, `FORAGE_WOOD 0.03` | `animals.py` | assumed | grazing-utilisation order of magnitude |
| Kleiber `293 kJ kg^-0.75 d^-1`, FMR ×2.5, `CoT = 10.7·m^-0.32` | `animals.py` | cited | standard allometry, species-independent |
| Density-dependent mortality `0.004 + 0.012·n_local` | `animals.py` | assumed | stands in for predation and disease; no predator is modelled |
| Material parameter sets | `materials.py` | cited ranges | typical values per class, not from a specific site investigation |
| DEM, climate fields, boreholes of the demo | `site.synthesize` | synthetic | marked `provenance.source = synthetic` |
| "Reconstruction error" on a synthetic site | `site.build_from` | synthetic | truth and samples come from the same generator: **circular**, diagnostic only |

## The circularity to keep in mind

On a synthetic site, the boreholes are sampled from a "truth" column produced by
the same rule that assigns facies. Any reported reconstruction error is therefore
a self-consistency check of the interpolation code, **not** an accuracy claim.
`site.build_from` only reports `topsoil_depth_mae_m` when it is given a truth
column, and the report labels the data source.

Real accuracy requires real data: a DEM, boreholes with logged intervals, and
climate records. The IO layer accepts them; nothing in the verified path assumes
synthetic input.

## What this means for use

- Comparing intervention A against intervention B on the **same** site: the
  assumed and cited parameters largely cancel, so the comparison is meaningful.
- Quoting an absolute capacity, an absolute NPP, or an absolute animal
  population: not supported by the parameter layer.
- Uncertainty output: it propagates the distributions you supply. If those
  distributions are guesses, the probability of failure inherits that.
