# blockworld 使用说明（中文）

## 这个库回答什么

给定一个场地（DEM、钻孔、气候），某个干预（换填、降水、植被替换、改重力……）
**会不会改变可行性判据**，以及**这个结论对不确定输入有多稳**。

它不预测真实场地会怎样。参数层是量级标定，只能做相对比较——这一点在
[`PROVENANCE.md`](PROVENANCE.md) 里逐项标注了。

## 安装

```bash
git clone https://github.com/Xbotsd/blockworld.git
cd blockworld
pip install -e .
```

装不上（没有网络）：直接

```powershell
$env:PYTHONPATH="src"; python -m blockworld --help
```

## 三步走

```powershell
# 1. 生成可编辑的数据模板（换成你自己的 CSV）
python -m blockworld template data\site

# 2. 跑一个研究：基线 + 干预 + 失效概率 + 敏感性排序
python -m blockworld study examples\study_landing.json --out out_study --mc 60 --morris 6

# 3. 看一个完整例子（合成场地，约 13 秒）
python -m blockworld demo --out out
```

第 3 步会生成 `out/report.html`（六个图层的交互沙盘）和 `out/sandbox.png`
（替换前后对比）。

## 在代码里用

```python
from blockworld import Criteria, Intervention, Region, Study
from blockworld.io import load_site

study = Study(
    site=load_site("data/site/site.json"),
    criteria=Criteria(
        purposes=("infrastructure", "landing"),
        landing_site=Region.circle(600, 300, 150),   # 把验证点固定在处理区
    ),
    interventions=(
        Intervention("换填 8 m 砂砾", [
            {"op": "material", "material": "gravel_dense",
             "top_depth": 0, "bottom_depth": 8, "region": {"kind": "all"}}]),
    ),
)
result = study.run()
print(result.passed())   # 每个干预之后各判据是否通过
print(result.flips())    # 哪些判据发生了翻转
```

支持的原子操作：`material`、`elevation`、`water_table`、`precip`、`pft`、`gravity`。
参数越界、本构不匹配、气候包络不符、替换深度超出柱底——都会抛异常，不会
静默产生一个"能算但没有物理意义"的世界。

## 不确定性

```python
from blockworld import Distribution, Parameter, monte_carlo, morris

params = [
    Parameter("软黏土 c", {"kind": "material_prop", "material": "clay_soft", "prop": "c"},
              Distribution("uniform", 8, 40)),
    Parameter("足垫直径", {"kind": "lander", "field": "pad_diameter"},
              Distribution("uniform", 0.2, 0.9)),
]

mc = monte_carlo(study, params, n=200, seed=1, intervention=study.interventions[0])
print(mc.baseline["infrastructure"]["p_fail"], mc.intervention["infrastructure"]["p_fail"])

mr = morris(study, params, r=6, seed=1, intervention=study.interventions[0])
for row in mr.ranking("landing")[:3]:
    print(row["param"], row["mu_star"], row["sigma"])
```

为什么不用秩相关排序：确定性、单调的单点扫描下 Spearman 必然饱和到 ±1，
没有信息量。Monte Carlo 给失效概率，Morris 给影响强度 `mu*` 与非线性指标 `sigma`。

## 常见坑

1. **判据永远在固定场地上评估**。干预区与验证点不重叠时，结论不会变——这是刻意的，
   避免"改哪就在哪通过"。局部处理时请显式指定 `landing_site` / `foundation_site`。
2. **`spin_years > 0` 很贵**：基线跑一遍，每个干预再跑一遍。生态判据才需要，地工判据用 0。
3. **生态 + Monte Carlo** 只在当前植被状态下有意义；要问气候情景，必须重跑植被。
