# Data

## Layout

```
data/
└── site/            # generated by `blockworld template data/site`
    ├── site.json
    ├── dem.csv
    ├── temp.csv
    ├── precip.csv
    └── boreholes.csv
```

The committed copy is the **template**, not a dataset: the DEM is a linear ramp,
the climate is constant, and the four boreholes are identical. It exists so that
`blockworld study examples/study_landing.json` runs out of the box. Replace the
files, keep the schema.

## Formats

### `site.json`

```json
{
  "grid": {"nx": 8, "ny": 8, "cell": 100, "x0": 0, "y0": 0},
  "gravity": 9.81,
  "seed": 1,
  "elevation": {"csv": "dem.csv"},
  "temp":      {"csv": "temp.csv"},
  "precip":    {"csv": "precip.csv"},
  "boreholes": {"csv": "boreholes.csv"},
  "provenance": {"source": "your dataset name"}
}
```

- `grid.nx / ny` — number of blocks along x / y.
- `grid.cell` — block size in metres.
- `elevation`, `temp`, `precip` — either `{"csv": "file.csv"}` or an inline
  `ny × nx` array. Shapes are validated; a mismatch names both shapes.
- `provenance.source` is copied into results and the report. Use it.
- `seed_pool` (optional) restricts which plant functional types may establish.

### `dem.csv`, `temp.csv`, `precip.csv`

Plain numeric matrices, `ny` rows × `nx` columns, comma separated, no header
(a single header row is tolerated). Units: metres, °C, mm/year.

### `boreholes.csv`

```csv
x,y,ground,top,bottom,material,source
200,200,20,0,1,silt,survey
200,200,20,1,4,clay_soft,survey
200,200,20,4,9,sand_dense,survey
```

- One row per interval; intervals for the same `(x, y)` must tile `0 → bottom`
  without gaps or overlaps, otherwise the loader reports the missing depth.
- `material` must be a key in `blockworld.materials.LIBRARY`.
- `source` is free text (`survey`, `control`, `borehole-2019`, …).

## Adding a material

```python
from blockworld import materials

materials.LIBRARY["my_silt"] = materials.Material(
    key="my_silt", name="场地粉土",
    gamma=18.6, c=9.0, phi=27.0, E=14.0, nu=0.32, k=2e-6,
    models=("mohr-coulomb", "hardening-soil"),
    source="site investigation 2025, BH-03",
)
```

Every material carries its validity domain (`phi_max`, `c_max`, `gamma_min/max`);
values outside it are rejected at replacement time rather than clamped.
